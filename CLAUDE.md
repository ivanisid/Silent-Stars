# Silent Stars — standing instructions
- Never add explanatory micro-text to the UI: no hint captions, helper text, "// description" lines,
  legends, notes under controls, mock disclaimers, or extra options the product/user didn't ask for.
  Only real product copy or user-given text, verbatim. If an explanation seems needed, ask.
- Readability first, especially in KARRAKIN: Cinzel caps ≥10px; check all 10 houses incl. light
  ones (glass, promise).
- Ukrainian UI, UPPERCASE labels, Lancer rules text stays in English. No emoji.
- Colours only via CSS variables from styles/theme.css; never hard-code a theme hex in components.
